# Пять минут с ApexFlow

Демонстрация проводится на свежем расчёте предоставленных данных. Статическая страница и ручной синтетический режим проверяют интерфейс, но не подтверждают анализ банковского набора.

## Подготовить реальные примеры

```bash
docker compose down
docker compose run --rm --build pipeline
docker compose run --rm --no-deps ui python -m ui.demo_examples
```

Последняя команда печатает JSON с фактическим периодом, временем завершённого расчёта и `examples`: приоритетный non-seed, иной профиль потоков, depth=4 (при отсутствии — изолят). Числа и gid берутся из текущих файлов; `edge_to_verify` содержит направление, сумму и количество операций. Если в наборе нет нужного профиля, команда его не придумывает.

Сохраните вывод локально для репетиции, не публикуя банковские данные на Pages. Прочитайте evidence, проверьте входы/выходы и правило в [методологии](methodology.md). Основной запуск `docker compose up --build --force-recreate` пересчитает результаты и откроет UI на localhost:8501; затем повторите генератор, чтобы примеры соответствовали последнему расчёту.

- Участник 3 отправляет актуальные код/артефакты на платформе и сохраняет подтверждение. До этого сдача не считается завершённой.

## Ответы жюри

| Вопрос | Ответ |
|---|---|
| Это вероятность преступления? | Нет: role_score — поддержка эвристической роли, priority_score — относительная очередь проверки. |
| Почему без обучения? | Нет разметки ролей; baseline проверяем по правилам и инвариантам. Оценка точности требует разметки. |
| Что даёт банку? | Очередь, основания, исходные связи и следующий шаг. Экономию времени и потерь без измерений не заявляем. |
| Как учтена неполнота? | Узлы сохранены, depth=4 и seed имеют оговорки; terminal не выводится из одного обрыва графа. |
| Как работает без интернета? | Зависимости в образе, файлы локальны, SVG без CDN. Первой сборке нужна сеть. |
| Можно внедрить завтра? | Это прототип; промышленный доступ, аудит, банковские интеграции и эксплуатационные испытания — отдельная работа. |
| Что сделал AI? | Помогал писать, проверять и исправлять код и документы. Участники выполняют личную проверку и объясняют свои решения. |
